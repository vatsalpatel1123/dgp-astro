## 🎯 IndexNow Submission

IndexNow allows instant notification to search engines (Bing, Yandex, etc.) when content changes.

### Submit Your Sitemap
```bash
# Replace YOUR_API_KEY with your actual IndexNow API key
curl -X POST "https://api.indexnow.org/indexnow?url=https://dentistrygrowthpartners.com/sitemap-index.xml&key=YOUR_API_KEY"
```

### Get IndexNow API Key
1. Go to https://www.bing.com/indexnow
2. Generate your API key
3. Create a file: `public/YOUR_API_KEY.txt` with the key inside
4. Submit URLs using the API
