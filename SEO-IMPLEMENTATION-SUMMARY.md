**Features:**

- Filters out backup/old files
- Weekly change frequency
- Priority: 0.7 (balanced)
- Includes last modification dates
- Properly formatted XML

**URLs:**
- https://dentistrygrowthpartners.com/sitemap-index.xml
- https://dentistrygrowthpartners.com/sitemap-0.xml

#### B. Manual Sitemap (Backup)
**File:** `sitemap-manual.xml`

**Features:**
- Custom priority settings:
  - Homepage: 1.0 (highest)
  - Service pages: 0.9 (very high)
  - About/Case Studies: 0.8-0.85 (high)
  - Blog/Location pages: 0.7-0.75 (medium-high)
- Custom change frequencies
- Manually curated for important pages
- Includes image sitemap schema

**URL:** https://dentistrygrowthpartners.com/sitemap-manual.xml

### 5. ✅ Automation Scripts

#### A. Bash Script (`ping-search-engines.sh`)
**For Linux/Mac users**
- Automatically pings Google
- Automatically pings Bing
- Provides IndexNow instructions
- Shows manual submission links

```bash

./ping-search-engines.sh
```

#### B. PowerShell Script (`ping-search-engines.ps1`)
**For Windows users**
- Automatically pings Google

- Option to open Google Search Console

**Usage:**
